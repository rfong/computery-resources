Some of my favorite computery resources.

### Before you dig in: do our preferred learning modalities match up?

- I have a semi-photographic visual memory and I read with extremely high speed+comprehension, so I overwhelmingly prefer textbooks, written articles, diagrams, and interactives.
- I have a really hard time absorbing info through audio lectures.
- I have excellent spatial intuition, so if something is not spatially obvious it's probably a blindspot for me.
- I prefer establishing foundational understanding over gratuitous short-term payoffs, so I tend to go for resources that are very thorough.

My resource recommendations might not be a good fit for your learning style if you are more of an audio/video learner, have difficulty with spatial intuition, or prefer to be given some instructions quickly rather than being firehosed with an excessively thorough explanation when learning about something for the first time.
